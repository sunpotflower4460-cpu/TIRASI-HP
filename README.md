# TIRASI-HP / Flyer Studio

イベントHPを保ちながら、ブラウザでチラシを作成・保存できるReact / TypeScript / Viteアプリです。

## チラシを作る

`/editor` の「チラシスタジオを開く」、または `/studio` から始めます。

- **イベントチラシ**: 編集済みの日時・出演者・会場を反映。イベントに追従するか、現在の内容を固定コピーにするか選べます。
- **自由制作**: 見出し・本文・画像から作成。作品展、ワークショップ、ショップ告知、メニュー、教室、地域の催しのひな形があります。日付・会場・Open Micは必須ではありません。
- **既存画像の加工**: 元の文字や構図を保ち、色・粒子・網点・版ずれ・退色などを調整する非破壊フィルターです。生成AIによる描き直しではありません。

**旧版「生音 A4」もイベントチラシのギャラリーから選択できます。** 従来の丸ゴシック、カード、4配色を保持し、文字の収まりと出力を改善しています。旧版はA4専用で画像枠はありません。

新デザインは、ライブハウス、シティポップ、ネオン、リソグラフ、アコースティック、インディー、フェス、ボタニカル、フォレスト、水彩、スイスグリッド、ギャラリー、マガジン、昭和ポップ、和紙、ステッカー、パーティー、アールデコ、セリフ、情報優先の**20構図**です。配色12種は構図と独立し、見出しのゴシック・明朝・丸ゴシックも変更できます。

本文ブロックの追加・順番・表示、チラシだけの文字上書き、画像位置、サイズ別の配置、取り消し・やり直しに対応します。調整済みの配置がある場合、新しい構図への変更は元の制作物を残すコピーとして行えます。

## 出力

| サイズ | PNG | 印刷 / PDF |
|---|---|---|
| A4 縦 | 2480×3508px（300dpi相当の画素数） | ブラウザ機能 / 210×297mm |
| A4 軽量版 | 1240×1754px | 同上 |
| SNS 縦 | 1080×1350px | PNG専用 |
| SNS 正方形 | 1080×1080px | PNG専用 |
| ストーリー | 1080×1920px | PNG専用 |

「PNGを生成」後に「PNGを保存」または「共有」を選びます。文字のはみ出し・重なり・必須情報不足・元画像欠損は出力前に通知し、解消するまで出力を止めます。文章を短くする、任意の詳細を減らす、別の構図・サイズを選ぶなどで調整してください。文字を無言で切り捨てたり、極端に小さくして成功扱いにしたりしません。

印刷はA4・倍率100%・余白なし・背景の印刷を設定してください。紙やブラウザ設定によって色や余白は変わります。印刷所向けの塗り足しは含みません。

## 保存・復元

下書きと原画像はこのブラウザのIndexedDBに保存します。旧v1のlocalStorage 3キーは削除・上書きせず移行元として保持します。旧単体JSON / 一覧JSONと、バージョン付きv2 JSONに対応します。読み込みは全件検証と内容確認後に確定し、不正レコードの無言除外はしません。

- **画像入り完全バックアップ**: ワークスペース、原画像のバイト列、SHA-256、加工設定を1つのJSONパッケージに含めます（上限64MB）。別ブラウザへの実際の復元をテストしています。
- **この制作物だけ完全バックアップ**: 1制作物と参照イベント・原画像を保存します。大きな一覧を個別に退避する場合にも使えます。
- **JSONのみ保存**: 原画像を含みません（上限4MB）。画像不足を検知した復元は現在の保存データを上書きしません。
- **直前の保存を確認 / 移行前の原JSONを退避**: 保存直前の状態や旧データを取り出せます。

画像の検証・完全バックアップにはHTTPSまたはlocalhostを使用してください。PNG / JPEG / WebPは8MB・1600万画素・長辺8192pxまで。SVG・HEICには対応していません。画像は実際にデコードして検証し、元画像を勝手に加工・削除しません。サムネイルは縮小した画像を共有し、原寸画像は書き出し時に読み込みます。原本のEXIF等も完全バックアップに含まれる場合があります。

ブラウザデータはユーザー削除・容量制限の影響を受けます。重要な制作物は端末へのバックアップを確認してください。保存失敗時は内容をメモリに保持し、別タブとの競合では上書きを停止します。

## 公開HPと下書きの違い

| 経路 | 表示するデータ |
|---|---|
| `/`, `/flyer` | `src/data/defaultEvent.ts` の公開済みイベント |
| `/editor` | このブラウザのイベント下書き |
| `/studio` | このブラウザの制作物 |
| `/preview/event/:id` | イベント下書きのA4 |
| `/preview/document/:id` | 制作物の下書きプレビュー |

下書きURLは同じブラウザでのみ有効です。旧 `/preview/event-:id` も読み込めます。下書きを編集しても公開HPやSNSメタ情報は変わりません。

公開する場合は公開用データを書き出し、`src/data/defaultEvent.ts` を更新し、レビュー・ビルド・公開作業を行います。HTMLメタ情報・JSON-LD・1200×630のOG PNG/SVGは公開元からビルド時生成します。選択済みのvol.6（2026-05-09）を保持し、開催情報を独断で作り替えていません。

ログイン認証、クラウド同期、有料API、外部生成AI、自動公開は追加していません。外部画像URLはネットワークへアクセスします。完全オフライン動作は保証していません。

## 開発・検証

```sh
npm ci
npm run dev
npm run test
npm run build
npx playwright install chromium
npm run test:e2e
```

Node.js 22.12以上を使用してください。Vercel: Vite / Build `npm run build` / Output `dist`。

- 単体40件、Chromium E2E 18件（新20構図×4サイズ=80 PNGを含む）。
- v1移行の4段階中断、同時初期化、保存失敗、競合、入れ子の不正JSON、完全バックアップの別コンテキスト復元、原画像の保持と6加工の再現性を検証。
- 比較画像: [デザイン20種](docs/evidence/template-contact-sheet.png) / [旧版4配色](docs/evidence/legacy-palette-contact-sheet.png) / [6加工](docs/evidence/effect-contact-sheet.png)。[実測結果](docs/evidence/render-matrix.json) / [デザインレビュー](docs/DESIGN_QUALITY_REVIEW.md)。
- 実iPhone/SafariのOS共有UIと物理印刷は未検証。Chromiumの390px画面とA4ブラウザPDF（1ページ）は検証済みです。

フォントはFontsourceからローカル配信します（Noto Sans JP / Noto Serif JP / Zen Maru Gothic、OFL-1.1。ライセンスは `public/licenses`）。sharp（Apache-2.0）はビルド用OG画像生成専用です。Vitest（MIT）、Playwright（Apache-2.0）、fake-indexeddb（Apache-2.0）はテスト用でブラウザに配布しません。PNG用html2canvasは旧版の出力時に遅延読み込みします。
