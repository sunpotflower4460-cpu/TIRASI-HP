# ライブ制作を中心にした改善

2026-11-16。ユーザーの主用途は定期的なライブ告知。毎回の入力を省き、旧版のようにタイトル・開催情報・出演者がフォームから自動で紙面へ入ることを優先する。

- 既存PR-B #37（基準5042252）で継続。main / 本番へ自動反映しない。
- イベント制作の初期デザインを旧版A4へ。新しい制作物のみが対象で、既存の選択・原画像・上書き・配置は保持する。
- 最初の編集タブはライブ情報。日付・回数・開始・料金・出演順を一画面で入力し、会場・主催等の固定情報は折りたたむ。詳細な自由制作は追加機能として残す。
- 「次回分を作る」で、既存の本文・会場・出演者・デザインを引き継ぐ。次回日付はユーザー入力、回数は編集可能な候補。新イベントと新チラシを同じWorkspace更新で追加し、前回を変更しない。
- 過去の出演者の入力候補、名前の複数行追加、時刻の一括設定を用意する。自動時刻は明示操作のみ。表示を名前だけにしても時刻の原文は残す。
- 20構図は共通のライブ情報を自動配置する。イベント用は見出しと絵を抑えて出演者・日時・会場を優先し、自由制作の構図はそのまま残す。
- ライブ向け旧版＋7構図を先に案内し、全20種へ展開できる。新たな選択肢の数を増やすことを品質の代わりにしない。
- Undo/Redo、linked/snapshot、バックアップ、件数制限、公開と下書きの分離を保つ。新機能の保存・再読込・次回複製・原画像・全出力の回帰を検証する。
