# Bundled artwork: provenance

Files: the 16 plates in `src/assets/posters/*.webp`, added in commit `26ae21b` (2026-11-19).
`docs/DESIGN_QUALITY_REVIEW.md` records that they were generated for this project, then cropped and made
transparent.

Statement by the owner (2026-11-25): the generators were **Claude and Codex**.
The files carry no generator metadata, and no per-file record names the model used. Photographic and painted
plates come from an image-generation model (Claude does not generate raster images itself), so they should be
treated as OpenAI image output obtained through Codex.
