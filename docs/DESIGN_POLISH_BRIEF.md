# デザイン再制作のブリーフ

2026-11-16。ユーザーの「各選択肢のクオリティを最大限ブラッシュアップ」を受け、PR-B #37 内で20構図を再制作する。基準HEADは `b8d1a11`、mainは `a270aee`。旧版A4と保存済みの本文・配色・配置を維持する。

## 批評と方針

前版は、上部の小さな幾何学装飾、同じ大きさの見出し、枠で囲った二段組が多く、説明文ほどの個性が実画像に出ていなかった。Storyで構図差が薄まり、会場・注意書き・Open Micも同じ文字の塊になっていた。出力成功だけでは美的品質の十分な根拠にならない。

公開OSSの [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) を読んで設計・実画像の批評手順に適用。特定の主役、題材に根拠のある表現、文字の階層、余白、不要な装飾の削除を判断軸とする。第三者ポスターや素材の転載はしない。

## 共通トークンと原則

- 色: 胡粉 `#fafaf7`、墨 `#20201e`、朱 `#a1372b`、藍 `#192c46`、夜 `#171c2d`、金 `#e5bc68` を代表とし、既存12配色のテキスト対比を守る。色替えは構図数に数えない。
- 書体: 和文はNoto Sans JP / Noto Serif JP / Zen Maru Gothic。数字・欧文はBarlow Condensed / Cormorant Garamondを役割に合わせて組み合わせる。いずれもOFL、自己配信。本文の最小18（1000幅基準）を維持。
- 組版: タイトルをポスターの主役にし、空間を使って対比をつける。会場、出演、補足を論理的に分割し、長さに応じて組み直す。本文に一律のカード枠をかけない。
- 和文見出し: Google BudouX v0.10.4の日本語モデルと純粋parser（Apache-2.0）を同梱し、文節と行の長さを両方考慮する。ユーザーの明示改行を優先する。長文は既存の安全な折返しへ戻す。DOM処理・他言語モデル・外部APIは含めない。
- 絵: オリジナルのCanvasベクターを主役として設計。音楽・自然・印刷技法の題材に結びつけ、画像なしでも成立させる。写真があれば専用の作品枠へ置換。紙目・網点は小さく決定的な描画にする。
- サイズ: A4 / SNS縦 / 正方形 / Storyのそれぞれで、見出し・絵・情報の比率と位置を調整。Storyでも各構図の特徴を残す。
- 保護: 全文・元画像・手動配置を保持。必須文字の安全域と可読性を測り、超過時は出力停止。画面・PNG・A4印刷で共通Canvas仕様。
