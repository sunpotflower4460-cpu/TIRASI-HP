## 2026-11-19の紙面改訂

同じ「生音 vol.6」で[変更前後の4組](evidence/poster-comparison.webp)を比較できる。変更前はmainの `7afc86d`、両方ともA4・各構図の推奨配色。現行の全構図は[ライブ](evidence/template-contact-sheet.png)と[自由制作](evidence/designs-free.png)に掲載した。

- 写真・銅版画・木版画・水彩などの図版16点を今回のために画像生成し、トリミングと透過処理を施して同梱。シティポップは夕景のパノラマ、ネオンは光を受けたマイク、ボタニカルは紙色が透けるオリーブの標本を主役にした。別配色では同じ図版を選択色の濃淡へ写す。自分の写真は元の色と位置設定を使う。
- スイスと情報優先は月日・年・曜日・時刻・料金を分けて表示。和紙はかすれた円相と落款、アールデコは対称の扇と中央の活字で構成。出演表は切符風の罫、タイムライン、名前を先に読む演奏会形式、縞の表などを使い分ける。
- 自由制作は文章量に合わせて横長の絵、縦長の標本と本文、作品と解説の段組を使う。「本文欄の見出し」は本文とは別の書体・大きさで描画。旧版A4は丸いカードと4配色を保ち、年と月日、出演時刻、演者名の強弱を整えた。
- 画像加工6種は、コピーの濃い黒、朱と藍の二色、青からピンクへ移る照明などで調子を分けた。網点の大きさは原画の明るさに応じて変化し、網点の間隔と粒子の位置は紙面の幅を基準にする。[原画と6加工](evidence/effect-contact-sheet.png)

## ライブを繰り返し作るための仕上げ

ユーザーの主用途に合わせ、基準5042252からライブ制作を主動線にした。新規だけを旧版A4から開始し、タイトル・出演者・開催情報を最初のフォームから直接入れる。会場・主催などは折りたたんで引き継ぎ、自由制作・画像加工は追加の用途として維持する。

- 「次回分を作る」は、元を変えず新イベントと新チラシを同時に作成する。日付は入力必須、回数は編集可能な候補。デザイン、固定情報、本文、上書きの見える内容、全サイズの配置、原画像参照を引き継ぐ。
- 出演者欄に過去の名前候補、複数行追加、上下移動、開始・演奏・転換からの時刻一括設定を用意した。名前だけの紙面にも切り替えられ、原文の時刻や休憩は失わない。
- ライブ情報の変更はイベントと制作物を一緒にUndo/Redoする。同じイベントの別デザインで後から変更された情報は、古い取り消し操作で上書きしない。
- ライブ用20構図は見出しと絵を縮め、出演者欄と案内を拡張。出演者名の設計上限を36〜44（1000幅基準）へ広げ、時刻との強弱を付けた。マガジンの細い出演欄も全幅へ組み替えた。自由制作の構図は維持する。
- ギャラリーは旧版＋音楽向け7構図を先に表示。全20種・12配色は引き続き選べる。スマートフォンのページ切り替えを小さな横一列に整え、入力中は画面を覆わない。

実際のPNGで、[時刻付き8種](evidence/live-designs.png)と[名前だけ8種](evidence/live-names-only.png)を見比べた。代表原寸でも出演者・会場・Open Micの階層、改行、罫との距離を確認した。[PCの入力画面](evidence/live-editor-desktop.png)、[390pxの入力画面](evidence/live-editor-mobile.png)、[次回作成](evidence/live-repeat-dialog.png)も保存。`scripts/render-live-proof.mjs`で旧版DOMを含む16枚の実PNGから再現できる。

単体56件、Chromium E2E24件、TypeScript/Vite buildが成功。通常80・名前だけ80・画像入りイベントと自由制作160、計320 PNGを生成・デコードした。旧版4配色と今回の2表示、次回複製後の原文不変、保存・再読込、共有と固定コピーのUndo、390px操作を確認した。実機Safari・OS共有・物理印刷は引き続き未検証。

## 20構図の初回再制作（5042252時点の記録）

前版は「小さな飾り＋似た二段組」が多く、構図名から期待する個性が実画像に出ていなかった。タイトルの強さ、絵の存在感、本文の階層も不足していた。前回の機械検証の成功を、美的な承認の代わりにしない。

- 題名の設計上限を172〜224（1000幅基準）へ広げ、見出し・副題・日時・出演者・詳細の役割を分けた。実際のサイズは文字数と紙面から計測して決める。
- 夕景、マイク、ギター、葉脈のある植物、森の木版画、水彩、円相、花の線画などをオリジナルのCanvasベクターとして制作。主役の絵には固有縦横比を持たせ、正方形で横につぶさない。
- 会場名・住所・主催・注意書き・Open Micを役割別に組版。行幅を実測するflow処理で、見出しの強弱と段落間隔を保って収める。長文を切り捨てず、最小文字でも収まらなければ出力停止。
- Google BudouX v0.10.4の日本語文節分割と行長の均衡を使い、見出しの「週末の、よ／りみち。」を「週末の、／よりみち。」へ改善。文節が収まるまで文字サイズも再探索し、明示改行と元の文字列は維持する。
- Barlow Condensedを時刻・数字へ、Cormorant Garamondを欧文セリフへ追加。和文はNoto Sans JP / Noto Serif JP / Zen Maru Gothicを使う。すべて自己配信、OFLライセンス同梱。
- ギャラリーを320px描画にし、構図の推奨配色を比較・適用できるようにした。同時適用はチェックで解除可能。選択・配色・Undoと本文保持をブラウザ検証した。

## 機械検証と限界

- 通常の20×4=80 PNGを2480×3508 / 1080×1350 / 1080×1080 / 1080×1920で生成・デコード。必須文字・寸法・実測安全域・文字同士の非交差を検査。要約は`evidence/render-matrix.json`。
- 画像入りイベント・自由制作の20×4×2=160 PNGも全生成・デコード。文字が写真枠へ入らないことを全件検査。許可された100単位のタイトル移動で写真と交差した場合に、出力停止できることも検証。
- 画像なしの自由制作60組（A4・正方形・Story）をproof scriptで別途描画。20種の本文・任意詳細と長い見出しを確認。
- 12配色は本文・紙、アクセント・紙、アクセント上の文字、薄い面・本文の4.5:1以上を数式検査。旧版4配色PNG、390px操作、Undo、完全バックアップ、印刷用画像とPNGの一致も回帰検証。
- 初回再制作ではunit44件 / Chromium E2E20件 / TypeScript・Vite buildが成功。ライブ優先後は上記の56件 / 24件。最新のGitHub CIはPR #37のChecksを参照する。
- 和文禁則・文節分割は組版の補助であり、JISの全要件を満たす専門DTPエンジンではない。手動の改行を尊重する。原画像と本文は変更しない。
- 実iPhone/SafariのOS共有UI、物理印刷、全実機のメモリ上限は未検証。美的な最終評価は自動テストの合格と区別する。
